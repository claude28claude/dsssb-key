# Fonts

Three families, self-hosted so that no request ever leaves this site and the
pages keep their typography with the aeroplane switch on. Each file is the
latin subset only, one static weight per file — about 139 KB for all seven.

| File | Family | Used for |
|---|---|---|
| `literata-400.woff2` `literata-600.woff2` `literata-italic-400.woff2` | Literata | headings, the official text, and key terms quoted inside an explanation |
| `inter-400.woff2` `inter-600.woff2` | Inter | the explanations, the tables, the cards — everything the site says in its own voice |
| `plexmono-400.woff2` `plexmono-500.woff2` | IBM Plex Mono | labels, chips, article numbers, and every figure marked inside a sentence |
